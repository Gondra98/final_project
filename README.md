### 1. [TankSimulation-yolo](https://github.com/Evann9/TankSimulation-yolo)
YOLO-based object detection server for a tank simulator environment.

- Flask API server for object detection
- YOLO inference pipeline
- Detection caching and confidence filtering
- Debugging endpoint for model and input-state checks
- Simulation-oriented AI perception module

### 2. [shipml_tp](https://github.com/Evann9/shipml_tp)
Machine learning project related to ship movement and AIS-style mobility data.

- Data preprocessing
- Feature engineering
- Classification model comparison
- Model evaluation using accuracy and F1-score

Data analysis project using Seoul restaurant/location-related data.

- Data collection and cleaning
- Exploratory data analysis
- Location-based insight generation
- Visualization-oriented analysis
